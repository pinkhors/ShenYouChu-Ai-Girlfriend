## 维护规则

- 行为、接口、数据模型变更必须同步更新对应文档，与代码同一个 PR；
- 每个文档的「待确认项」集中列出未决问题，给出默认建议；确认后原地更新并记录；
- 难以回退的架构决策写入 `docs/adr/`；
- 文档变更需评审。
