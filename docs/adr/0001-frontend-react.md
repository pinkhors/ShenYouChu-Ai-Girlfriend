# 前端框架选用 React

- 状态：accepted

桌面客户端在 Vue3 与 React 之间选择。两者在 Electron 中运行于同一 Chromium/V8，实测渲染差异只有毫秒级，对本项目秒级的模型与媒体链路没有实质影响，因此决策依据是生态与协作而非性能。

决定采用 **React + TypeScript**。核心理由是项目计划开源并面向全球开发者：React 的全球生态、人才供给和第三方库覆盖更广，更有利于吸引外部贡献者；本项目没有必须依赖 Vue 特性的场景，Live2D 与 Web Audio 均以命令式方式集成，与框架无关。

被否决的方案：

- **Vue3**：中文社区与单人开发效率有优势，但对本项目的全球开源目标帮助较小；若团队后续以 Vue 为主力可重新评估。
- **放弃框架或用轻量库**：桌面端界面复杂度不足以抵消组件化与生态带来的收益。

后果：

- 前端目录、命名与组件规范按 React 执行；
- 流式文本与音频更新需遵循"避免整树重渲染、音频不进响应式状态"的约束；
- 框架切换属于高成本决策，不在开发中期进行。
